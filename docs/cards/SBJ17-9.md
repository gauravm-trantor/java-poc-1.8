## Assess, the card lead, 2026-11-27

### What the card changes

The pipeline names its ready-made steps by a moving label (`actions/checkout@v7`) and pulls the HBase image by a moving tag (`harisekhon/hbase:1.4`). A publisher can move a label, so the pipeline could change without a commit of ours. The card replaces each label with the exact commit it points to today, and the image tag with its digest. Nothing the tests do changes.

### Design

A text edit of two files, no code. Each `uses: actions/<name>@<label>` becomes `uses: actions/<name>@<40-hex commit> # <release>`, the form GitHub's own security guide uses and that Dependabot reads and updates. The compose line becomes `image: harisekhon/hbase:1.4@sha256:<digest>`; Docker uses the digest and ignores the tag, and people still see the version.

The commit for each label is read just before the edit with `gh api repos/actions/<name>/git/ref/tags/<label>` (a script, `scripts/ci/` beside the existing checks, so the result can be repeated); the release name is the newest release whose tag points at the same commit. The digest is read with `docker buildx imagetools inspect`.

Acceptance tests, written in Test design, in the style of the existing `scripts/ci/AC*.py` checks (Python, one per criterion, named by the criterion):
- `AC1-actions-pinned.py`: reads every workflow file; fails on any `uses:` not followed by 40 hex characters and a `# v` comment.
- `AC2-hbase-image-digest.py`: reads the compose file; fails unless the hbase image carries `@sha256:` and 64 hex characters.
- `AC3-pins-match-labels.py`: for each pinned step, asks GitHub which commit the release in its comment points to and fails on a mismatch; for the image, compares with the registry's digest for `1.4`. It needs the network and `GITHUB_TOKEN` (read only).
- AC4 is the pipeline itself: required checks `maven` and `ui`, with the existing AC4 HBase check in the maven job.

These run in a new job of `ci.yml` named for this card, like SBJ17-2's acceptance job, limited to this card's pull request so they do not hold later cards to this card's facts. AC1 and AC2 would hold for every later card too; making them permanent is a later decision.
